## 归档规则（沿用工程既有口径）

1. 一条功能线一份 PR 报告，文件名 `PR-REPORT-<主题>.md`（大写，连字符分隔）。
2. 报告必须含**三份证据**：①可复跑的断言 ②反向自检（改坏必须变红）③真机物证（坐标/日志/截图路径）。
3. 「明确未做」必须写，且写清"为什么没做 / 什么条件下该做"——别让后来人把它当 bug。
4. 新增报告后**在本文档登记一行**，否则等于没归档。
5. 版本号一律以 `AndroidManifest.xml` 为准；文档里不抄版本号常量（升版本必假红，2026-10-21 已踩过）。
