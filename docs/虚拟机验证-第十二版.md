## 一、测试环境（本机实测可用）

| 项 | 值 |
|---|---|
| SDK | `D:\Android\Sdk`（emulator / platform-tools / system-images/android-36/google_apis/x86_64） |
| AVD | `pet411` · android-36 · x86_64 · 1080×2400 · density 420 · RAM 4 GB |
| 启动 | `emulator.exe -avd pet411 -no-window -no-audio -no-snapshot -gpu swiftshader_indirect -port 5554` |
| 装包 | `adb -s emulator-5554 install -r <apk>` |
| 驱动 | `adb shell input tap x y`、`uiautomator dump`、`screencap` |

### ★ 一个必须交代的差异：ABI
正式包是 **arm64-v8a**（`lib/` 里 6 个 .so：onnxruntime / sherpa-onnx / llama 等），
而 AVD 是 **x86_64** ⇒ 直接装会 `INSTALL_FAILED_NO_MATCHING_ABIS`。

所以虚拟机测试用的是**去掉 `lib/` 的对照组包**（`dist/DeepSeekPet_v7.6_emulator-smoke.apk`，5.5 MB）：
- 用 `zipfile` 重打包（去掉 `lib/*` 与 `META-INF/*.SF|RSA|DSA|MF`），再用同一把 `debug.keystore` 重新签名；
- **只用于验证 UI / 交互 / 任务链路**；本地 GGUF 模型、sherpa 语音这类**依赖 .so 的功能在虚拟机上不可验证**，
  正式包（arm64）不受影响，仍然照旧出包。

## 二、真跑之后发现的问题（离线断言全绿，但界面是坏的）

| # | 现象（截图可见） | 真因 |
|---|---|---|
| 1 | 页签只剩**一个字**：「对」「轨」 | 每个页签是「文字 + 固定 22dp 下划线」嵌在竖向 LinearLayout 里，测量时容器被那条 22dp 压住 ⇒ 文字被挤成一字一行 |
| 2 | 中间**一片空白**，看不到「探索未至之境」 | 空态判据用的是 `events.isEmpty()`，而会话一建就有一条 `session` 事件 ⇒ 空态**永远**进不去 |
| 3 | 桌宠悬浮窗**压在对话流正中间**，还自己乱走 | 悬浮桌宠会自己做 `DSPWander` 漫游（日志 `walk 740→575`），我加的"贴边"动作抢不过它 |
| 4 | 右上角一个「⚙ 控制台」，进去是权限/日志页 | 这是我上一版加的调试页 —— **用户明确说没用** |
| 5 | 输入框下面还有一行「／ 指令 ＠ 文件或对话 ＋ 添加附件 —— 这三项本轮暂未开放」 | `/` 和 `@` 已经真能用了，这行是过期废话，看着就像"捡漏" |

## 三、这一版改了什么

1. **页签重做**：不再用"文字 + 独立下划线"的嵌套，改成 **App 自己的选中胶囊**（`accentSoft` 底 + `accent` 字 + 粗体），
   未选中是灰字。既修掉测量 bug，也更符合"主题同步 App"（底部导航就是这种形态）。
2. **空态判据换成"有没有可见对话"**（user/assistant/tool/error 四类），新增 `hasVisibleContent(...)`。
3. **桌宠在工作模式里不再靠浮窗**：进页面 `ACTION_HIDE_TEMP` 收起浮动娃娃（它会漫游、会挡字），
   改在**顶栏左侧显示桌宠头像**（`PetAvatar.load`）；离开时按全局设置恢复
   （`hidePetInApp` 为真就继续隐藏，否则 `ACTION_SHOW_TEMP` 放回去）。
4. **控制台整页删除**：`DshActivity.java` 删除、`AndroidManifest.xml` 注销、
   页签行与抽屉里的两个入口都删掉（断言改成"文件不存在 + 清单里没有 + 工作模式代码里不出现"）。
5. **删掉那行过期提示**。

## 四、断言跟着改（不然套件会红）

`verify_dsh_work.py`：
- 清单断言从"两个界面都注册"改成"**只注册工作模式，控制台已注销**"；
- 新增"**控制台整页删掉**"（`DshActivity` 不在工作模式代码里 + 文件不存在）；
- 页签断言从"有下划线 View"改成"**App 式选中胶囊**（`tabLabel(...)`，且 `tabChatBar` 不再出现）"；
- 桌宠断言从"发 SHOW_TEMP"改成"**发 HIDE_TEMP + 顶栏头像 `PetAvatar.load`**"；
- 把那行过期提示的断言改成"**这行必须不存在**"。

`reverse_check_dsh_work.py`：反向项 **T** 改成破坏"顶栏头像"，必须变红。

`verify_page_theme.py`：面向用户的 Activity 从 **9 个改成 8 个**（少了控制台）。

> ★ 教训：**离线断言只能证明"代码里有这句话"，证明不了"界面对不对"**。
> 页签被压成一个字、空态永远不显示、桌宠挡字，这三件事所有断言都是绿的。
> 以后 UI 改动一律先上 AVD 看一眼，再谈"通过"。
